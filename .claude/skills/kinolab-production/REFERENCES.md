## Selection notes
- Cinema Skills: production stages, stable shot IDs, style bible and handoffs; repository self-identifies as structure-first, so do not assume every planned skill is implemented/tested.
- VargHQ: ad strategy, product fidelity, prompt structure, image-first approval, cost control, sound and media QA; do not inherit its API dependency or mutable model pricing.
- EL4CTEO: Blender workflows and tested script discipline; select commercial-relevant modeling, PBR, lighting, camera, animation, rendering and QA.
- RobLe3: staged Blender workflow, reference-locked refinement and honest validation; do not require MCP.
- sunithvs: deterministic timeline, captions, timed graphics, audio layers and resumable rendering; do not require its browser rendering stack.
- ElevenLabs: voice/audio specialty workflow; no API dependency.
- Awesome Agent Video Skills: discovery catalogue, not a quality certification.
- Anthropic: progressive disclosure, clear triggers, direct references, deterministic scripts and real evaluations.
