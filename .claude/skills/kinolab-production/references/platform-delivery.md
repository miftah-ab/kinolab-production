# Platform Delivery, Aspect Ratios and Captions

## Confirm destination first

Ask which platform, placement and use: organic post, paid ad, website, in-store display, TV or client archive. Requirements change. Check current official platform documentation before claiming a specific maximum duration, codec, file size, safe zone or disclosure requirement.

## Aspect ratio workflow

- 9:16 vertical: common full-screen mobile placement; compose for mobile and keep critical text/brand/CTA away from interface overlays.
- 16:9 horizontal: common web/YouTube/landscape delivery; use deliberate landscape composition.
- 1:1 square and 4:5 portrait: create deliberate reframes if requested.
- Multiple ratios: do not merely crop the center. Plan protected subject areas, alternate framing, separate overlays and revised shot compositions. Create separate exports and QA each one.

## Technical export

Set exact dimensions, frame rate, progressive scan, codec, pixel format, color space, audio codec/sample rate and bitrate based on the destination and source footage. Preserve the source frame rate unless there is a reason to convert. Avoid upscaling low-resolution sources as if it creates real detail. Check color space tags and SDR/HDR compatibility.

YouTube's published upload recommendations currently include MP4, H.264, AAC-LC or Opus audio, 48 kHz audio, source-matched frame rate, and BT.709 for SDR. These are YouTube-specific recommendations, not universal export rules. Re-check the official page before delivery.

## Captions and subtitles

- Provide accurate transcript and synchronized captions when dialogue or meaningful audio is present.
- Include speaker identification and meaningful non-speech audio where relevant.
- Proofread names, numbers, prices, punctuation and localization.
- Supply SRT or another requested caption file where supported, plus burned-in captions if the creative needs them.
- Do not rely on automatic transcription without checking it against the actual audio.
- Keep captions readable and clear of platform UI and CTA.
- For multilingual work, create separate subtitle tracks/versions and have a fluent speaker review translation.

## Final deliverable matrix

For each version list: filename, ratio, dimensions, frame rate, duration, codec/container, audio, captions/subtitles, destination, and QA status. Keep masters and platform derivatives separate.
