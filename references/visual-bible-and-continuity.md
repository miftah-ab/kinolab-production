# Visual Bible and Continuity

Create a compact visual bible before generating a sequence with recurring subjects, locations, products or visual motifs.

## Lock these elements

- Product truth: shape, dimensions/proportions, materials, packaging, labels, colors, logo placement and features.
- Subject/character: age range if relevant, wardrobe, hair, skin tone, distinctive features and allowed variation.
- Environment: location, architecture, surfaces, props, time of day and weather.
- Art direction: palette, contrast, texture, atmosphere and reference style.
- Cinematography: framing language, camera height, lens perspective, depth of field and movement rules.
- Lighting: source direction, softness, contrast, practical lights and continuity.
- Post look: color grade, grain, halation and finishing.
- Sound palette: music character, ambience, Foley and signature sounds.

## Reference roles

For every reference image, state its role:
- Product identity reference.
- Character identity reference.
- Location / set reference.
- Composition reference.
- Lighting / mood reference.
- Style reference.

If references conflict, define precedence. Product identity and required brand facts take precedence over aesthetic inspiration. Do not let a style reference alter the actual product.

## Continuity rules

- Reuse approved reference images where supported.
- Repeat essential identity details verbatim across relevant prompts.
- Keep wardrobe, props, environment, time of day, lighting direction and screen direction consistent unless a deliberate change is specified.
- Track product orientation, label visibility, liquid/food state, hand positions and object placement.
- Avoid asking an image/video model to render readable text, logos, labels, UI or precise numbers. Add these in post wherever possible.
- Do not claim a model will preserve identity perfectly; inspect every generated shot.
